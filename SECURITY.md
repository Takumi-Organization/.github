# Política de seguridad

Si encuentras una vulnerabilidad en cualquier proyecto de Takumi Organization, **no abras un issue público**.
Usa *Security → Report a vulnerability* en el repositorio afectado (avisos privados de GitHub).

Incluye: versión o commit, pasos para reproducirlo e impacto estimado. Se responde lo antes posible.
Nunca publiques credenciales, tokens ni datos personales en issues o pull requests.
