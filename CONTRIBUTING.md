# Cómo contribuir

1. Abre un issue antes de un cambio grande.
2. Una rama por funcionalidad o corrección.
3. Commits en español, en imperativo y concretos.
4. Antes de pedir revisión: compila, pasa las pruebas y no versiones secretos.
5. Un pull request, un propósito: no mezcles refactor con funcionalidad.
